Подготовка

Как пользоваться редактором

1. Один раз подключить GitHub

Нажмите Подключение, укажите репозиторий и вставьте fine-grained token. Токен хранится только в текущей сессии браузера и не записывается в файлы сайта.

2. Права токена

Достаточно доступа к одному репозиторию и разрешения Contents: Read and write. Не давайте токену лишних прав.

3. Публикация

Редактор коммитит изменения в выбранную ветку. Если GitHub Pages публикуется из этой ветки, изменения появятся после стандартной сборки Pages.

4. Адрес редактора

/Affiliate_Lab/admin/. Ссылки на него в публичном меню нет, страница закрыта от индексации.
